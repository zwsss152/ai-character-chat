# 开发清单

目标是可理解、可验证的原创 AI 角色系统。首轮由助手实现基础设施，维护者先学习；按实际证据推进，不把工程测试当成人设能力。

## 0.3.0 首轮地基

| 工作 | 验收证据 | 状态 |
|---|---|---|
| 角色规格进入输入，旧卡兼容 | 捕获身份、边界、开场白和当前问题 | 本轮实现，验证见 verification.md |
| 角色快照 | 修改角色卡不改变旧会话 | 本轮实现，验证见 verification.md |
| 多轮及完整轮次裁剪 | 顺序、轮数、字符预算和必要内容检查 | 本轮实现，验证见 verification.md |
| SQLite 会话、恢复、删除 | 重启、隔离和删除级联 | 本轮实现，验证见 verification.md |
| 请求去重、失败与并发 | 无半轮、重复成功、同会话冲突和其他会话可用 | 本轮实现，验证见 verification.md |
| HTTP 适配器 | 模拟服务验证格式、用量、超时和错误脱敏 | 本轮实现；真实服务效果待验证 |
| 网页与追踪 | 新建、续聊、刷新、删除、断线重试、模式显示 | 本轮实现，验证见 verification.md |
| 安装包和文档 | 包内角色卡与网页资源可用 | 本轮实现，验证见 verification.md |

实际结果以验证记录为准。“本轮实现”不表示未运行的检查已经通过。

## 后续顺序

| 顺序 | 任务 | 完成标准 |
|---|---|---|
| 1 | 本人追踪一次请求并修改 mock | 能解释模块职责，贡献记录有尝试 |
| 2 | 真实模型基线 | 固定服务、模型、参数和问题，保留回答、失败、用量和耗时 |
| 3 | 20 组人设开发题及未见测试题 | 明确评分规则，开发和测试分开 |
| 4 | 人设一致性对照 | 固定模型和预算，比较提示方案，报告失败和分歧 |
| 5 | 第二个原创角色 | 不同价值观和边界，角色隔离和规格复用 |
| 6 | 世界观检索 | 有来源、未知处理、无检索和有检索对照 |
| 7 | 长期记忆 | 可查看、更正、删除；误记、隔离和删除测试 |
| 8 | 角色微调及综合实验 | 数据划分、训练日志、同底座对照和复现报告 |

训练属于长期研究方向；效果不提升也记录。当前不增加游戏任务系统、引擎、语音、动画或公开部署。

## 每次开发完成条件

1. 明确改变的行为和待验证问题。
2. 实现并运行相关检查。
3. 更新实际验证与贡献来源。
4. 提交可复查改动，检查远端 CI，未验证效果保持待确认。

此清单不是自动日程，学习、服务条件与新实验结果可能调整顺序。
