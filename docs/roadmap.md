# 学习与研究路线

长期目标是游戏中 AI 角色的身份、性格、知识与记忆。当前用本地网页研究对话流程，不据商业产品体验推测其内部实现。

首轮基础设施由助手完成，维护者先学习；本人尝试记入 [贡献记录](contributions.md)。代码已存在不等于已经理解。

## 从基础开始

| 任务 | 前置知识 | 亲手完成 | 理解证据 |
|---|---|---|---|
| 追踪请求 | Python、JSON、HTTP | 跟踪 mock 消息，画输入输出 | 区分角色卡、提示、Provider、消息和追踪 |
| 修改规格 | 列表、校验、测试 | 改表达方式，在新旧会话发送 | 解释快照与 mock 不执行性格 |
| 多轮输入 | 消息序列、预算 | 历史上限改为 1，检查第三轮追踪 | 区分全历史和模型近期输入 |
| 持久化 | SQLite、事务、异常 | 重启、模拟失败、删除 | 解释完整轮次及模型调用在事务外 |
| 真实调用 | HTTP、环境变量、状态码 | 用获准服务发送固定问题 | 记录模型、用量、耗时、错误，保护密钥 |
| 人设评测 | 基线、评分、抽样 | 开发题与未见测试题分开 | 明确规则，保留失败，不只看截图 |

每次选一个小问题，先写本人理解和尝试，再求提示。接口检查验证流程，无法证明模型人格。

## 后续研究

| 方向 | 学习内容 | 实验与交付 |
|---|---|---|
| 长对话一致性 | 提示、上下文、失败分类 | 简单提示、结构化规格和系统改进对照，固定模型与预算 |
| 世界观知识 | 检索、嵌入和来源 | 无检索、关键词、向量检索，区分检索失败和回答失败 |
| 长期记忆 | 事实提取、更正与删除 | 历史、摘要、带来源事实对照，分析误记与虚构 |
| 训练基础 | 向量、梯度、损失、注意力 | 修改 PyTorch 小网络，解释验证曲线和过拟合 |
| 角色微调 | LoRA、数据划分、泄漏 | 同底座前后对照、日志、数据版本与复现命令 |
| 作品整理 | 设计、报告和演示 | 说明问题、方案、效果、限制及本人贡献 |

API 和训练分别推进。付费实验先估计资源、费用上限和停止条件；微调无提升也保留完整报告。

## 当前边界

- 服务、规格、上下文、持久会话、HTTP 适配、网页及追踪：本轮工程实现，实际结果见 [验证记录](verification.md)。
- mock：离线回显，无人格生成。
- 真实模型人设表现：需要独立对照实验，工程测试不证明效果。
- 长期记忆、检索、训练、语音、动画、游戏引擎：尚未实现。
- 本人能力：按贡献记录与独立解释判断。

## 一次研究怎样做

问题 → 可反驳假设 → 简单基线 → 固定测试 → 改一个因素 → 分析全部结果与失败 → 下一次实验。

同时改多个部分只能比较整体，不能归因于单项；保留未见问题，报告评分分歧及样本限制。

学习材料可选 [CS50P](https://cs50.harvard.edu/python/)、[FastAPI](https://fastapi.tiangolo.com/tutorial/)、[PyTorch 基础](https://docs.pytorch.org/tutorials/beginner/basics/intro.html)或 [Hugging Face 大模型课程](https://huggingface.co/learn/llm-course/zh-CN/chapter1/1)。每阶段只选一门主课，其余按问题查阅。
